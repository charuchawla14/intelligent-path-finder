# 🚦 Intelligent Path Finder

An AI-powered traffic-aware route optimization system that combines Machine Learning and the A* Search Algorithm to identify the most efficient travel route between locations. The system predicts traffic conditions using historical traffic data and recommends optimal paths by minimizing congestion and travel time.


## 📌 Project Overview

Intelligent Path Finder is designed to simulate a smart navigation system capable of making route decisions based on predicted traffic conditions. The project integrates Machine Learning models with graph-based pathfinding techniques to create a dynamic route recommendation system.

By leveraging traffic prediction and intelligent search algorithms, the application helps users discover efficient routes while considering real-world traffic patterns.


## ✨ Key Features

* Intelligent route optimization using the A* Search Algorithm
* Traffic prediction using Machine Learning models

## 🚀 System Workflow

1. User selects source and destination locations.
2. Historical traffic data is processed and analyzed.
3. Machine Learning models predict traffic conditions.
4. Traffic predictions are used to assign route costs.
5. The A* Search Algorithm evaluates available paths.
6. The most efficient route is selected based on distance and predicted congestion.
7. Results are displayed through graphical visualizations and route animations.


## 🧠 Algorithms Implemented

### A* Search Algorithm

The A* Search Algorithm is used to identify the shortest and most efficient path between source and destination nodes. It evaluates routes using a combination of actual travel cost and heuristic estimates to improve search efficiency.

### Random Forest Regression

Random Forest Regression is used to predict traffic conditions by analyzing historical traffic data and multiple traffic-related factors. The ensemble learning approach improves prediction accuracy and robustness.
